## 自行执行核心测试

测试不附带任何游戏资源。需要合法游戏安装中的原版 `Assets/Fonts` 目录；使用已经应用补丁的目录会不符合原始资源校验。

```powershell
.\tests\Run-CoreTests.ps1 -OriginalFontsDirectory 'D:\SteamLibrary\steamapps\common\AoEDE\Assets\Fonts'
```

脚本会将输入资源复制到唯一的临时测试目录；不会把测试改动写回原游戏目录。完整测试生成两轮字库并演练进程中断，可能需要数分钟。参数细节以脚本的 `param` 声明为准。
