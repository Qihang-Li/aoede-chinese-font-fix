# 玩家使用说明

适用游戏：第一代《帝国时代：决定版》Steam 版（App 1017900）。本工具是非官方社区项目。

## 开始使用

1. 将完整压缩包解压到一个普通文件夹。保留程序旁边的字体、许可证等文件。
2. 关闭游戏，等待 Steam 更新结束。
3. 双击 `AoEDE-Font-Fix.exe`。
4. 确认游戏目录。正确目录内应有 `AoEDE_s.exe` 和 `Assets`；不要选择 Steam 根目录或 `Assets/Fonts` 子目录。
5. 选择默认字体，先检查并预览，再应用。等待完成提示后再启动游戏。

默认字体来自思源黑体的简体中文区域版本，兼容性处理后名为 Aoe CJK Sans，按开放字体许可证分发。无需在 Windows 中安装该字体。

## 自选字体

选择静态 TrueType `.ttf` 文件。可分别选择常规和粗体；若没有粗体文件则使用常规文件。第一版不支持 TTC、可变字体和 CFF 格式 OTF。

字体必须覆盖游戏所需汉字；缺字时应用会停止。能打开的字体也不一定适合所有字框，先检查预览，再看游戏菜单与实际对局文字。自选字体须有允许相关转换用途的许可，尤其不要因为字体在电脑上已安装就认为可以转换或公开分发。

## 恢复原版

关闭游戏，打开工具，选择同一游戏目录并使用恢复功能。不要删除游戏目录里的 `AoEDE-Chinese-Font-Fix-backup` 文件夹。

程序发现未知游戏更新或其他 mod 改动时会停止，避免覆盖它们。不要通过删除状态文件、修改哈希或强行覆盖来绕过检查。若备份损坏或丢失，可通过 Steam 的“验证游戏文件的完整性”修复官方资源；此操作也可能覆盖其他游戏文件修改。

## 常见情况

- **资源不支持：** 检查是否是第一代决定版及正确目录；其他版本、已有字体修改和未知更新需要分别处理。
- **访问被拒绝：** 选择有写入权限的游戏库目录。工具不会主动申请管理员权限。
- **游戏更新后效果消失：** 先检查资源状态；只有工具确认支持时再应用。
- **繁体中文或日语也变了：** 游戏共用这些字体资源。同码汉字会一起变化；需要其他地区字形时恢复原版。
- **怀疑下载包被改动：** 比较与正式发布页相同版本的 SHA-256，并查看完整源码与构建说明。哈希一致本身不是无恶意代码证明。

工具只修改指定字体资源，不以解锁成就或改变玩法为目标。多人联机、新成就触发、Microsoft Store 与 Steam Deck / Proton 均无兼容保证。
