# 行为与安全说明

## 文件范围

程序读取用户选择的游戏目录以及字体文件，在本机生成字体纹理。应用或恢复只替换源码列出的 16 个 DDS 文件；备份、事务记录和候选文件保存到游戏目录下的 `AoEDE-Chinese-Font-Fix-backup`。

该备份目录包含用户本机的原游戏资源，不能作为公开发布素材上传。日志可能含本机路径，公开反馈前请检查内容。

预览保存于程序指定的临时目录或命令行 `--out` 路径；命令行 `--log` 只创建新日志，已存在的路径会被拒绝。日志输出还会拒绝游戏目录、选定字体、预览输出以及目录联接。请勿把任何输出指向重要文件。

## 程序设计

- 离线运行，没有账号登录、遥测或自动联网更新。
- 默认字体按进程私有方式加载，无需安装到系统字体目录。
- 不注入游戏进程，不修改注册表、存档或游戏逻辑。
- 检查游戏进程和已知资源哈希；未知状态停止。
- 安装前保存备份，使用事务记录处理失败和中断；恢复时验证当前文件，遇到第三方改动停止。

文件系统异常、断电、其他程序同时修改文件等仍存在边界情况。保留独立备份；不要在 Steam 更新游戏时操作工具。

## 开源与构建

源码公开使检查成为可能，并不代表已经接受独立机构安全审计。下载包与某份源码的对应关系也应通过发布记录和构建过程核查。SHA-256 只用于文件一致性检查。

发现问题时提供工具版本、游戏版本、错误提示和可复现步骤。不要上传密码、个人日志全文、完整游戏资源或未经许可的字体。收到可信问题报告后，应暂停推广受影响版本，修复并同步更新下载地址和指南。
