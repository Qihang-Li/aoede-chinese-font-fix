# 0.1.0 社区预览版

面向《帝国时代：决定版》第一代 Steam 版的非官方、离线简体中文字体修复与自定义工具。

## 本版内容

- 在玩家本机读取游戏资源，统一生成 16 份字体 DDS 的汉字区域，保留原有 FNT 排版信息及非汉字区域。
- 默认内置 **Aoe CJK Sans** 常规、粗体：由 Adobe 思源黑体 CN 2.005 静态化并更名，按 SIL OFL 1.1 分发。
- 提供字体预览、应用、原始备份和恢复功能。
- 支持选择包含所需汉字的静态 TrueType 字体；粗体文件可选。
- 通过已知字体资源的哈希识别支持范围，拒绝未知文件和冲突；安装前生成候选文件，恢复时核对备份与当前文件。
- 公开自写代码、构建脚本、测试及字体来源信息。程序离线运行，无须 Python 或 fontTools。

## 支持范围

- Windows 64 位、.NET Framework 4.8、Steam App **1017900**。
- 基线：游戏 Build **97381** / Steam Build **12673858** 所对应的已知字体资源；版本号本身不是兼容性判断依据。
- 不适用于 AoE II DE、Return of Rome、AoE III DE 或 AoE IV。
- Microsoft Store、Steam Deck / Proton 未验证。
- 自定义字体不支持 TTC 集合、可变字体或 CFF 格式 OTF；缺字会拒绝处理。

## 验证与限制

默认两种字重均已通过 Windows 私有 GDI/GDI+ 加载和全部 3,688 个目标汉字的覆盖检查。字体生成脚本在两次独立输出目录中产生了相同的 SHA-256。核心流程通过 57 项完整集成检查，包括逐像素保护检查、原样恢复和强制中断后的恢复；另通过 12 项快速检查。已在一台 Windows 11 电脑的实际 Steam 安装中应用并检查民族菜单、提示文字和单人对局界面。这些检查不代表所有电脑、界面或第三方字体均已验证。

游戏多个语言共用字体资源，修改会影响繁体中文、日语等语言中的同码汉字。游戏更新、Steam 验证文件或其他 mod 可能覆盖修改。项目不提供反作弊、多人联机、新成就触发或未来游戏版本的兼容保证。

下载 `AoEDE-Chinese-Font-Fix-0.1.0-win-x64.zip` 并完整解压，运行 `AoEDE-Font-Fix.exe`。请保留附带的字体、许可证和说明文件，并核对发布页上的 SHA-256。

国内备用下载：[百度网盘（0.1.0 成品包）](https://pan.baidu.com/s/1XwgLAi_XntuAjsHea5uo3g)，提取码：`bp6t`。下载后请核对预期 SHA-256：`5993a313a79477bece4442a91a364c9ce3639f76cb380ad86307a5c8a62166f1`。

需要撤销时先关闭游戏，再使用“恢复原样”。保留游戏目录中的 `AoEDE-Chinese-Font-Fix-backup`；遇到未知文件冲突时，不要删除备份或强行覆盖。
